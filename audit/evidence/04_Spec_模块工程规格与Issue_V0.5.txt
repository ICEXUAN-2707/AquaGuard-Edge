3: Spec V0.5 · 基于冻结契约 · 开发前须通过依赖 Gate
4: 1. 全局开发约定
5: 只通过公共 DTO 交互；公共 Schema 修改必须跨工作线 PR 审核并更新契约测试。
6: 每个 Issue 具备：目标、可改目录、入/出契约、成功用例、失败用例、验收命令、日志证据、回滚方案。
7: 优先跑通模拟数据端到端闭环，再逐步切换真实硬件、轻量 AI、华为云。
8: 目录及文件名属建议结构；Gate 0 审查已有仓库后冻结实际路径，避免重复造轮子。
9: 2. 推荐代码边界
10: firmware/（设备采集）、edge/adapters/（MQTT 输入）、edge/alignment/（M3）、edge/features/（M4）、edge/inference/（M5）、edge/decision/（M6）、edge/storage/（SQLite 事务）、edge/cloud/（M7）、web/（M8）、experiments/（回放/标注/评估）、contracts/（Schema/示例）、tests/。
11: M1｜ESP32 采集（主责 A）
12: 目标与实现：flow pulse/LD2410 UART/水接触；标准化时间与质量。
13: 完成定义：硬件样例、校准表、未知与失联测试。
14: 前置依赖：Gate0 固件路线与电平安全。
15: 代码审查重点：不得改变其他模块字段语义；新增兼容测试及异常路径，保留回退开关。
16: M2｜MQTT Adapter（主责 A）
17: 目标与实现：解析消息、接收时间、质量校验、去重、兼容原仓库 Topic。
18: 完成定义：标准观测 fixture、JSON 错误与重连测试。
19: 前置依赖：Gate0 原仓库通信。
20: 代码审查重点：不得改变其他模块字段语义；新增兼容测试及异常路径，保留回退开关。
21: M3｜时间对齐（主责 B）
22: 目标与实现：多路缓冲、事件时间、窗口发布/迟到、有效期、水位线。
23: 完成定义：AlignedWindow fixture；延迟/重启/乱序测试。
24: 前置依赖：M2 Schema。
25: 代码审查重点：不得改变其他模块字段语义；新增兼容测试及异常路径，保留回退开关。
26: M4｜特征融合（主责 B）
27: 目标与实现：12 项可解释特征、缺失掩码、跨窗口状态及检查点。
28: 完成定义：FeatureWindow fixture；在线/回放一致性测试。
29: 前置依赖：M3 窗口语义。
30: 代码审查重点：不得改变其他模块字段语义；新增兼容测试及异常路径，保留回退开关。
31: M5｜规则与 ML（主责 B）
32: 目标与实现：C0～C3；试验标注独立；降级规则；模型版本。
33: 完成定义：离线评估报告和推理测例。
34: 前置依赖：M4 特征版本。
35: 代码审查重点：不得改变其他模块字段语义；新增兼容测试及异常路径，保留回退开关。
36: M6｜安全决策（主责 C）
37: 目标与实现：水接触快速路径、唯一事件、四轴状态、确认与恢复。
38: 完成定义：状态机与重复事件测试；事务写入接口。
39: 前置依赖：M5/SafetySignal DTO。
40: 代码审查重点：不得改变其他模块字段语义；新增兼容测试及异常路径，保留回退开关。
41: M7｜SQLite Outbox + IoTDA（主责 A）
42: 目标与实现：统一事件事务存储、队列、重试、设备属性/消息适配。
43: 完成定义：断外网/重启/失败重试记录。
44: 前置依赖：M6 EventTransition。
45: 代码审查重点：不得改变其他模块字段语义；新增兼容测试及异常路径，保留回退开关。
46: M8｜Web & 实验平台（主责 C）
47: 目标与实现：总览/事件/实验三页；只读流与受控 ack API。
48: 完成定义：Playwright/接口用例、演示录屏、数据导出。
49: 前置依赖：M6 API 与 M7 状态。
50: 代码审查重点：不得改变其他模块字段语义；新增兼容测试及异常路径，保留回退开关。

124: 6. Spec 编写注意事项
125: 硬件 GPIO、波特率、脉冲系数、云区域、SDK API 签名仍是 Gate0 的待验证变量，禁止在 Codex Spec 里伪装成已确认。
126: 窗口 W/S/L 为默认配置且必须可注入测试。
127: “联系家属”属 C3 扩展，不能作为 M7 云适配完成判据。
128: 模型无法区分自动用水与遗忘关水时应拒判，不能伪造高置信度结论。
129: 产品迁移至用火仅保留契约扩展点，不引入真实火焰或燃气试验。
