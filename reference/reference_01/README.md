# 水知安 V0.5 开发资料包

按推荐阅读顺序：

1. `01_业务基线与冻结决议_V0.5.docx`：几轮讨论统一口径，P0 场景、M1–M8、五项 ADR、未验证事项。
2. `02_PRD_产品需求文档_V0.5.docx`：用户需求、MVP 边界、页面与业务验收。
3. `03_Architecture_Contracts_V1.docx`：双路径架构、数据结构、时间语义、事件状态机、数据库与接口。
4. `04_Spec_模块工程规格与Issue_V0.5.docx`：八模块技术执行边界、分工与任务拆分。
5. `contracts_example.json`：只作公共对象样例，实际开发需补充 Pydantic/JSON Schema、字段单位与校验规则。

## 冻结口径
本资料包基于当前对话中水知安 V0.4.1 五项 ADR 的设计决议。所有硬件、开源许可、本地仓库运行和真实 IoTDA 连接仍以 Gate 测试为准。文中建议的 API 路径/目录不是现存代码事实。
