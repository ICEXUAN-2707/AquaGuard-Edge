# M4-R02｜有效区间与基础流量特征

日期：2026-10-29。状态：本轮原型基础验证通过，M4 整体 PARTIAL。synthetic / prototype_only。

## 开发内容和思路
src/basic_flow.py 实现 flow_mean_lpm、flow_max_lpm、flow_active_ratio，同时输出内部 flow_coverage_ratio 与 valid_flow_sec 供核对。不是完整 FeatureWindow，也没有伪造检查点。
输入窗口和观测先经候选 DTO 校验，按 source_observation_ids 精确解析，检查引用完整、设备、来源及流量时间条件。将流量区间裁剪至窗内，按有效持续时间加权。缺失不补0；活动阈值使用严格大于0.1的实验口径。冲突重叠区间拒绝，不私自平均。输出是内部原型结果，额外诊断字段不塞进正式 DTO。

## 多次交叉检验
1. 四组手算：部分缺失、6与0的不同持续时间、全缺失、跨左边界加缺口；均值分别6、2、null、7。
2. 独立逐秒参考：100组固定随机序列，用30格已知/未知样本的直接求和计算均值、峰值、活动占比和覆盖；与区间算法逐项一致。种子20261029，测试不调用被测函数生成期望。
3. 与 M3 对照：上述随机序列及既有21条三源样例的有效覆盖一致。
4. 变形检查：30秒同流量拆成6个5秒区间，五项数值不变；0.25秒区间与阈值恰好相等行为明确。
5. 异常检查：缺引用、来源不符、重叠冲突和非法阈值被拒绝。自查补上非有限流量保护。
6. 单独运行基础模块测试，随后执行全部受影响回归；真实日志见 evidence/r02_isolated_tests.txt 和 r02_tests.txt。
