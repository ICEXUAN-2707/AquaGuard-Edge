# A 采购确认（2026-10-30）

结论：原清单可作为采购范围，但不能不核对版本就整单购买。按下面两批执行；尚未验证某个店铺SKU或套装的实际兼容性。

## 可以先购买

|物品|建议数量|必须选择的版本|
|---|---|---|
|ESP32开发板|2块|优先乐鑫ESP32-DevKitC V4、ESP32-WROOM-32E，已焊排针，附原理图；不要裸模组或随意换C3/S3|
|USB数据线|2根|匹配实际板接口；官方DevKitC V4为Micro-USB；必须可传数据|
|LD2410C|1个，预算允许2个|海凌科HLK-LD2410C，焊针及匹配连接线；卖家提供用户手册、UART协议及版本|
|YF-S201|1个，预算允许2个|明确YF-S201及输出电路资料；水路配件让同一卖家配齐|
|FC-37套装|2套|探头+比较器板+连接线，附模块原理图和AO/DO说明；不单买探头|
|通用用品|各1套|万用表、杜邦线、面包板、端子、绝缘托盘、固定件、量杯和接水桶；已有可复用|

板卡官方手册确认DevKitC V4使用Micro-USB，且存在不同模组变体，故必须指定版本：[乐鑫指南](https://documentation.espressif.com/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html)。雷达厂家页面列出5V工作供电与3.3V串口输出，但宣传页不能替代匹配版本UART协议：[海凌科产品说明](https://www.hlktech.net/index.php?id=65)。

## 确认后再购买或配齐

- **水流信号适配**：DFRobot的YF-S201产品资料列出5V供电时输出高电平大于4.7V。这不是可直接接ESP32 GPIO的依据，必须核对所购输出电路并设计电平适配。不能因为传感器可购买就直接接线。[供应商规格](https://www.dfrobot.com/product-1517.html)
- **水路接头和软管**：确认水流计实际螺纹标准、内外牙、密封方式，配两端接头、卡箍、垫片及匹配内径软管。G1/2不是软管内径。
- **电源与分配线**：取得实际板卡和传感器手册后核算容量、供电入口及电平；不要先买12V给开发板供电。USB可用于板卡初步验证，不自动证明足够给三传感器供电。
- **水泵**：先确认台架可达流量和水流计工作范围，再选择低压泵、独立电源及调流方案；低流量实验不一定落在传感器可靠测量范围。
- **FC-37**：未找到所购模块的确定原理图；无法提供电平/极性资料的店铺不应直接下单替代品。

第一轮不需要购买树莓派、云服务器、蜂窝模块或独立网关。电脑承担边缘端。以上是本项目最小台架方案，不是对任意店铺同名商品的兼容保证。

需要ESP32-DevKitC V4/WROOM-32E、YF-S201、FC-37完整套装、HLK-LD2410C做桌面台架。请提供实物照片、完整版本、引脚/原理图、供电与输出逻辑电平、雷达串口协议；配齐匹配数据线/模块连接线。水流计配两端接头、密封件及匹配软管。请明确哪些输出需要适配ESP32的3.3V输入。不能提供资料的替代型号先不要替换。
