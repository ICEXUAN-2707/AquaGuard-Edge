## 状态口径

- `NOT_STARTED`：执行或实现尚未开展；允许已有方案和采购准备。
- `IN_PROGRESS`：已有实现或执行成果，当前阶段尚未收尾。
- `PARTIAL`：限定范围已有成果，完整任务仍有未通过或未验证项。
- `PASS`：仅用于明确范围、有证据且完成相应评审的验收结果。本表没有新增任何放行。
