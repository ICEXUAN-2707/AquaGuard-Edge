## 本轮新增与边界

新增 mqtt_phase_evidence.py：只读截取水事件、转换数、消费 boot/cursor、重复与隔离计数；逐阶段验证 TTL、恢复唯一事件、ACK 不伪造、重复无额外水事件转换、重启身份和旧 boot 隔离。缺字段为 INCOMPLETE，条件不符为 VIOLATED；均使执行失败。

新增 mqtt_ack_summary.py：记录总行数、完成/未完成/非法行，以及有效完成记录的 p50/p95/max；不把失败记录从分母删除，拒绝负数/非有限/组成不一致时延和伪造 broker 确认。日志缺失为 INCOMPLETE，退出检查不会因此通过。阶段局部 SATISFIED 不升级为整体 acceptance_passed。

本轮只做离线短测，不注册/启动任务、真实 broker、长时实验或真实云。后续可并行：A 收集实物/标定证据；B 规划真实 trial 和标注；C 继续观测收口、PR 评审与部署设计。资源开通/真实联网/恢复实验仍按当前暂停边界另行授权。
