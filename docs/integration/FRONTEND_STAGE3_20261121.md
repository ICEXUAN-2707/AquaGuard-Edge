## 三阶段收口与人工验收

第一阶段公共框架和状态反馈、第二阶段总览和趋势、第三阶段事件和诊断均已实现。待人工验收后准备集成：

1. 总览：来源、快照时间、年龄、覆盖率含义清楚；未知不被解读为正常。
2. 可视化：5/15/30 分钟选择、实际样本时间与导出范围一致；明细表可读；接口失败不展示旧趋势。
3. 事件：确认仅代表知晓；关闭条件和不可操作原因清楚；原请求重试与证据披露容易辨认。
4. 诊断：运行记录、文件引用、参考评估与真实验收边界清楚；空结果与查询失败可区分。
5. 桌面与手机：导航、表格、按钮及键盘焦点可用；普通操作下跳转链接隐藏，键盘聚焦时可见并可跳到主要内容。

本轮尚未执行人工验收或 main 合并。后续集成应先核对最新主线差异并审查该分支，再固定最终实验版本；真实实验的暂停/启用遵循独立实验计划。
