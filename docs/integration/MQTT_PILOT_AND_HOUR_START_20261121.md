## 代码改动

- `scripts/mqtt_local_backend.py`：broker 启动显式使用 `-v`，确保 Windows 无控制台模式仍产生就绪日志。保留自有日志 + socket + 版本校验，不降低检查要求。
- `scripts/mqtt_awake_runner.py`：显式执行门控及只读 preflight 后才请求 `ES_CONTINUOUS | ES_SYSTEM_REQUIRED`；结束/异常时恢复原线程请求状态，记录 power-request.json。不修改电源计划，不要求显示器常亮，也不能阻止用户主动休眠。官方说明：https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-setthreadexecutionstate 。主机被强制挂起时仍依靠 OS 时钟、固定分母和退出证据判定失败。
- `tests/delivery/test_mqtt_awake_runner.py`：验证成功/异常均恢复、请求失败不执行、恢复失败不伪装成功。与后端、执行器及证据检查组合 54 项通过；原 broker 修复相关 36 项通过，两组不累加。
